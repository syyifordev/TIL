# 배열 두 배 만들기
자바에서 배열 쓰는 게 뭔가 다른 코드에서 썼던 배열들이랑 다른 느낌임

무슨 배열도 종류가 저렇게 많은지

안 되는 건 뭐가 이렇게 많은지

아 불편해 C# 하고 싶습니다

(궁시렁)

~~~java
class Solution {
    public int[] solution(int[] numbers) {
        int[] answer = new int[numbers.length];

        for(int i = 0; i < numbers.length; i++) {
            answer[i] = numbers[i] * 2;
        }

        return answer;
    }
}
~~~
